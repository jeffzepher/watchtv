# 孟源TV · 电视儿童动画测试版

基于 WatchTV 电视版，适用于 Android 9（API 28）及以上。首页从豆瓣获取同时标注「儿童」和「动画」的片单，选择影片后搜索随 APK 内置的来源，仅显示与所选片名同名的搜索结果。资源、片单与播放均由电视通过网络直接访问，不使用部署者的服务器。片单标签和来源信息来自第三方，无法保证每个标题、每条线路或剧集都适合儿童，请家长陪同检查。

首页为小猪佩奇、斑马百科、汪汪队、布鲁伊和拉布拉多警长提供快捷入口；其中拉布拉多警长也按官方名称《安全警长啦咘啦哆》搜索。附件默认内置 19 个用户提供的来源，测试时 360资源和 ikun资源的《猫和老鼠》HLS 播放列表可访问，非凡和量子可检索《安全警长啦咘啦哆》，已优先排列；单次抽样不能代表长期可用，电视的网络环境也可能不同。没有单独的来源设置或自由搜索入口。受限于上游，部分影片可能搜不到或无法播放。

安装：把 debug APK 复制至 U 盘，在电视文件管理器中安装；使用遥控器方向键和确认键选择影片、来源、线路及播放操作。不同电视固件可能限制第三方 APK 的安装或媒体解码。播放仅支持来源返回的可直连 HLS/MP4，使用电视系统播放器。播放器可能跟随播放列表的分片及重定向；请仅使用可信来源。

构建：JDK 17、Android SDK platform 35、Gradle 8.13，运行 `gradle :app:testDebugUnitTest :app:assembleDebug`。调试 APK 使用本机调试签名，仅供个人测试。覆盖更新要求签名一致。

电视版 0.2.4：首页快捷入口使用海报卡片，封面优先取自已配置来源；不可用时显示图形占位。搜索结果和剧集使用遥控器网格。播放以全屏显示，按方向键或确认键可呼出控制栏；返回依次进入剧集页和首页。小猪佩奇按来源标注的英语、未明确、中文分组，标注不代表实际音轨已验证；详情页可以将发现错标的结果标记为非英文。
