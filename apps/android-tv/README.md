# WatchTV 电视测试版

适用于 Android 9（API 28）及以上设备。程序本机访问用户导入的 Apple CMS JSON 影视来源和媒体地址，不需要 WatchTV 服务器。电视遥控器可操作搜索、来源启停、线路和剧集选择，以及播放控制。

## 安装与来源导入

将生成的 APK 拷贝到 U 盘，使用电视上的文件管理器安装。安装路径和是否允许安装第三方 APK 依电视固件而异。首次使用请在电脑的 WatchTV「来源管理 → 导出来源」导出 JSON，拷到 U 盘；在电视应用中选择「导入来源 JSON」。电视须提供 Android 文件选择器，否则需要兼容的文件管理器。

当前为试用版：搜索每个来源的第一页，最多显示 200 条；需要来源能由电视网络访问，支持返回直链 HLS/MP4 的 Apple CMS JSON；HLS 解码、不同编码、格式和外部播放器地址依电视系统及媒体源而定。播放器使用 Android 系统媒体组件，可能跟随流里的重定向和媒体分片地址，建议仅导入可信来源。推荐首页、收藏和观看历史暂未实现。

## 构建

使用 JDK 17、Android SDK（platform 35）和 Gradle 8.13：在本目录执行 `gradle :app:testDebugUnitTest :app:assembleDebug`。生成的 debug APK 使用本机 Android 调试签名，仅供个人测试。更新覆盖安装要求签名一致，请妥善保留签名密钥，正式分发需要专门的发布签名。
