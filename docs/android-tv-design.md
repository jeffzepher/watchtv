# WatchTV Android 电视版方案

目标设备：雷鸟 65V69E，Android 9，2 GB RAM。程序独立安装在电视上，访问来源不经用户服务器。

首版采用原生 Android 电视应用：使用遥控器方向键、确认与返回操作；提供来源 JSON 导入、多来源搜索、选择来源与剧集、播放直接可用的 HLS/MP4。播放兼容性取决于电视编码能力及资源源的访问限制。来源和设置保存在电视本地。

独立应用需要在 Android 上实现网络请求、来源解析和播放器，不能直接将 Windows Electron EXE 转为 APK。使用 Android 支持库与适用于电视的播放器，并保留内网访问防护、网络超时与错误提示。电视 Android 9 对应 API 28；具体 CPU 架构和厂商安装限制仍需在设备上验证。

验收：构建可安装 APK；检查无触屏时的焦点导航、搜索、来源导入、剧集切换与本地播放；最终在用户的实际电视上测试安装及视频解码。先完成可操作的电视版基础功能，再考虑推荐、收藏和观看记录等扩展功能。
